# Fintech API landscape: testing reference guide

**Reference document. Nothing was built or tested against these APIs.**

## In one minute

A reference compiled to understand the API categories a BFSI company integrates, and what a good test suite checks for each. It has 24 examples in 9 categories, each with an endpoint, a sample request and response, and test scenarios. The page labels it as a reference document, not a built or tested system.
